# 退换货与退款政策

## 七天无理由退货

- 符合条件的商品自签收次日起 7 天内可以申请无理由退货。
- 商品应保持完好，附件、赠品、包装和防伪标识齐全。
- 定制商品、已拆封的贴身用品及页面明确标注不支持退货的商品除外。

## 质量问题退换货

- 商品存在质量问题时，应上传能够说明问题的照片或视频。
- 审核通过后，平台承担合理退货运费。
- 是否换货取决于商品库存；缺货时默认进入退款流程。

## 退款时效

- 退款审核通过后，款项原路退回。
- 支付宝或微信通常在 1 至 3 个工作日到账。
- 银行卡通常在 3 至 7 个工作日到账，具体以银行处理时间为准。

## 人工处理场景

- 超过售后期限但存在特殊情况。
- 退款状态超过 7 个工作日没有变化。
- 订单包含多件商品且仅部分退货。
- 系统无法识别订单或支付记录。
